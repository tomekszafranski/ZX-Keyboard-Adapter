# ZX-Keyboard-Adapter
Adapter for ZX81/ZX Spectrum keyboards


There is no computer without keyboard




When you build ZX Spectrum clone/compatible machine you have to decide whether to use original keyboard which would be 


or more convenient modern version. Most popular are probably [Superfo Harlequin 128 Keyboard](https://www.pcbway.com/project/shareproject/Supero_Harlequin_128_Keyboard.html) (tactile) and [ZX Spectrum Keyboard](https://www.pcbway.com/project/shareproject/ZX_Spectrum_Keyboard.html) (mechanical). Keyboard Adapter handles all above options (original and modern keyboards) and even works with ZX81 allowing to use its keyboard for your Spectrum and vice versa (set two jumpers vertically instead of horizontally, becasue ZX-81 has two rows swapped).
