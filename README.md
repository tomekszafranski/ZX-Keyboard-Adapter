# ZX-Keyboard-Adapter
Adapter for ZX81/ZX Spectrum/ZX81 keyboards

When you build Sinclair ZX Spectrum clone or compatible machine you have to decide what kind of keyboard to use. If you are aiming for original case you will probably use original membranes with FFC tape connectors. If you are just experimenting or thinking about different case you can use one of more convenient modern versions. Most popular are probably [Superfo Harlequin 128 Keyboard](https://www.pcbway.com/project/shareproject/Supero_Harlequin_128_Keyboard.html) (with tactile switches) and [ZX Spectrum Keyboard](https://www.pcbway.com/project/shareproject/ZX_Spectrum_Keyboard.html) (with fully mechanical cherry-type switches). Those Harlequin keyboard are designed for Spectrum like machines but they use wires or goldpin connectors that gives you more flexibility. If you are building your own version you are not even made to have two 8+5 pins connectors if only you can transfer all signals.

Keyboard Adapter handles all above options (original and modern keyboards) and even works with ZX81 allowing to use its keyboard for your Spectrum and vice versa (set two jumpers vertically instead of horizontally, becasue ZX-81 has two rows swapped).
